# Silent Critique: Coding-Agent Access

**Verdict: ready for feasibility review, not a trial report.** The revised copy adds rules for interpreting joint and divergent outcomes, separates telemetry loss from voluntary stopping, and distinguishes the prospective pilot from a powered comparison. It preserves the original manuscript and prior review.

- **Structure:** randomized access, delivered patch and delayed same-person performance are separate objects. This is a current-setting contrast, not historical before/after evidence.
- **Methods:** pilot leakage of condition to coders and patch reviewers. Clarify feedback before follow-up; the new assumption is explicit and can be changed before recruitment.
- **Analysis:** assigned treatment is the main contrast. CAP elapsed time is not automatically active time; fewer observed minutes may accompany worse completion. No moderation or learning mechanism is established merely by correlations among phase outcomes.
- **Figure and results:** preserve the existing workflow as design, not data. The added table shows possible interpretations without observed values.
- **Ethics:** document approval, consent, limited logging, storage and separation from work and grading before any data collection.

Priority: test task-variant comparability and reliability, fix meaningful effect sizes, then freeze uncertainty and attrition handling.
