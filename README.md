# The Junior’s Curve: How Coding Agents Change the Work of First-Year Developers

**Working paper and study design.** When first-year software developers maintain unfamiliar code, how does access to a coding agent affect what they spend time doing, the quality of the work, and what they can later do unaided?

This is a proposed software study, not a claim about historical change or all of STEM. No participants have been recruited and no new results are reported.
